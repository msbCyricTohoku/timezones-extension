# Simple Time Zone Clock

This extension shows the current time for a number of cities.

## Installing as an Unpacked Extension

1. Download or clone this repository.
2. Open Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the folder containing `manifest.json`.
5. The extension will appear in your list and can be opened from the toolbar.

## Files
- `manifest.json` – Chrome manifest file.
- `popup.html`, `popup.css`, `popup.js` – popup implementation.
- `icons/` – icons used by the extension.
